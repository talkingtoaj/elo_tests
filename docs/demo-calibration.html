Calibrate a course

Every course is a little different. Some questions are harder than their band says, and student answers are cleaner in some subjects than others. Here a made-up course takes a 20-question calibration run. The library learns from it, then you can see whether the learning helped.

Things to try

  1. 30 students, noisy answers. The default curve is wrong. Run it, then compare the test. Fitting the curve fixes how sure the library claims to be.
  2. 30 students, then compare. Look at the "everything" row. Fitting every question's difficulty from so few answers can make the test worse.
  3. 300 students. Now fitting difficulty pays off, and the flags are mostly right.
  4. 30 students, 50 questions. A smaller bank gives each question more answers, but gives the test fewer questions to choose from.
